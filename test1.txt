1.Go to play.google.com/console and sign in
2.Click "Create app"
3.Fill in: App name, language, select App, select Free
4.Go to Production → Create new release
5.Upload the app-release.aab file
6.Fill in release notes (e.g. "First release")
7.Click Save → Review release → Start rollout

Before submitting, make sure these sections are completed (left sidebar):

Store listing → app description, screenshots, icon
App content → fill the questionnaire, and tick "Yes, contains ads"
Data safety → select that the app collects ad data
Privacy policy → add a URL (I can generate one for you)

Keep the .jks file and password safe forever — you'll need them to update the app in the future."*
